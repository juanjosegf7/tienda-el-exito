# Sistema de Gestión de Inventario - Tienda El Éxito

## Descripción

Aplicación de consola desarrollada en Java 21 para gestionar el inventario de una tienda de barrio.

## Objetivo

Aplicar los fundamentos de programación orientada a objetos, colecciones y manejo de excepciones mediante la implementación de un sistema de inventario.

## Tecnologías

- Java JDK 21 LTS
- Visual Studio Code
- Git y GitHub

## Funcionalidades previstas

- Registrar productos alimenticios y electrónicos.
- Almacenar productos mediante HashMap.
- Buscar productos por código.
- Mostrar el inventario.
- Manejar errores mediante excepciones personalizadas.

## Estado

Fase 1: configuración del entorno y creación del proyecto.

## Ejecución

Compilar desde la raíz:

`javac -encoding UTF-8 -d out src/com/store/StoreApp.java`

Ejecutar:

`java -cp out com.store.StoreApp`
